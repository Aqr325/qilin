## 二、P1 问题（需修复）

### P1-1：Windows Agent `collect_cpu()` 阻塞事件循环

**文件**: `agent-win/src/__main__.py:83-87`

```python
def collect_cpu() -> Dict[str, Any]:
    return {
        "usage": psutil.cpu_percent(interval=0.5),  # ← 阻塞 500ms
        "count": psutil.cpu_count(logical=True),
    }
```

**问题**: `psutil.cpu_percent(interval=0.5)` 会阻塞当前线程 500ms 做时间片采样。在异步 `run()` 主循环中被同步调用，每次心跳间隔 10 秒 → 累积阻塞 500ms（占 5%），且 `run()` 内的日志打印再次调用 `collect_cpu()` 和 `collect_memory()`，单轮循环阻塞时间可达 ~1.2 秒。

**影响**: 在高并发或密集任务场景下可能延迟任务处理；`asyncio.sleep(0.1)` 的 100ms 粒度本意是快速响应 stop，但 500ms 阻塞让其失效。

**修复**:
```python
async def collect_cpu() -> Dict[str, Any]:
    # 非阻塞：用 interval=None 获取瞬时值（与采样对比会有波动，但适合心跳）
    usage = psutil.cpu_percent(interval=None)
    return {"usage": usage, "count": psutil.cpu_count(logical=True)}
```

或保持阻塞但异步化：
```python
def collect_cpu_sync() -> Dict[str, Any]:
    return {"usage": psutil.cpu_percent(interval=0.5), "count": psutil.cpu_count(logical=True)}

async def collect_cpu() -> Dict[str, Any]:
    loop = asyncio.get_running_loop()
    return await loop.run_in_executor(None, collect_cpu_sync)
```

### P1-2：`compute_health_score()` 心跳新鲜度重复计算

**文件**: `backend/app/services/agent_service.py:141-145`

```python
def compute_health_score(agent: Agent, heartbeat: Optional[AgentHeartbeat] = None):
    hb_freshness_score = _score_heartbeat_freshness(agent)   # ← 调用 1
    hb_freshness_value = (
        round((datetime.now(timezone.utc) - agent.last_heartbeat).total_seconds(), 1)
        if agent.last_heartbeat else None
    )  # ← 重复计算（与 _score_heartbeat_freshness 内部逻辑相同）
```

**问题**: `_score_heartbeat_freshness()` 内部已经计算了 `(datetime.now() - last_heartbeat).total_seconds()`，外部又重复计算了一次 `hb_freshness_value`。两者用同一个 `datetime.now()` 但调用了两次，存在微小时间不一致。

**修复**:
```python
def _score_heartbeat_freshness(agent: Agent) -> tuple[int, Optional[float]]:
    """返回 (score, freshness_seconds)。"""
    if not agent.last_heartbeat:
        return 0, None
    age = (datetime.now(timezone.utc) - agent.last_heartbeat).total_seconds()
    score = 100 if age < 30 else (70 if age < 60 else (40 if age < 120 else (10 if age < 300 else 0)))
    return score, round(age, 1)
```

## 三、P2 问题（代码质量/可维护性）

### P2-1：`_check_auto_register_limit` 全局可变状态

**文件**: `backend/app/services/agent_service.py:36-47`

```python
_auto_register_counts = defaultdict(list)

def _check_auto_register_limit() -> bool:
    now = time.time()
    key = "auto_register"
    _auto_register_counts[key] = [t for t in _auto_register_counts[key] if now - t < 60]
    if len(_auto_register_counts[key]) >= 10:
        return False
    _auto_register_counts[key].append(now)
    return True
```

**问题**: 全局 `defaultdict(list)` 在异步上下文中无锁保护。虽然单进程 FastAPI 使用单线程事件循环（无并发写入），但如果未来迁移到多线程 uvicorn workers，该函数会竞态。

**修复**: 改用 `threading.Lock` 保护，或用 token bucket 替代：
```python
import threading
_auto_register_lock = threading.Lock()

def _check_auto_register_limit() -> bool:
    with _auto_register_lock:
        # ... 原逻辑
```

hb = await AgentHeartbeatRepository(db).get_latest(agent.agent_id)  # 用 agent.agent_id (business key)

### P2-6：`upgrade_agents()` 升级任务回滚时 Agent 状态未恢复

**文件**: `backend/app/services/agent_service.py:646-679`

```python
for aid in agent_ids:
    agent = await agent_repo.get_by_agent_id(aid)
    if agent:
        agent.status = "upgrading"          # ← 标记升级中
    task = AgentTaskModel(...)
    db.add(task)
    # ...
await db.flush()
except Exception:
    await db.rollback()
    raise
```

**问题**: 如果在 `db.add(task)` 之前 `db.flush()` 已提交了 `agent.status = "upgrading"` 到 DB，然后后续 `db.add(AuditLog)` 或另一个 agent 的循环中抛异常 → `rollback` 会撤销所有变更，包括 Agent 状态恢复。但实际上 **flush 之后 rollback 是有效的**（SQLAlchemy 的 rollback 会回滚 flush 的所有变更），所以这里**不是 bug**。

**备注**: 逻辑正确，无需修复。只是提醒后续 reviewer 确认 `rollback` 确实回滚了所有 agent 状态。

## 四、P3 问题（风格/注释）

### P3-1：`_score_disk()` 参数类型注释缺失

```python
def _score_disk(disk_json: Optional[Dict[str, Any]]) -> int:
```

`Dict[str, Any]` 覆盖了 dict 和 list 两种类型，但实际传入的是 `heartbeat.disk_json`（可能是 list）。建议加注释说明接受的两种类型。

### P3-2：`local_status.py` `_get_cpu_percent()` Windows 路径用 wmic

```python
r = subprocess.run(["wmic", "cpu", "get", "LoadPercentage", "/format:list"], ...)
```

wmic 在较新 Windows 版本中被弃用（建议使用 `Get-WmiObject` / `Get-CimInstance`）。当前 wmic 在 Win10/Win11 仍可用，但微软已标记为 deprecated。

### P3-3：`batch_restart_agents()` 错误处理吞掉原始异常

```python
except Exception as e:
    errors.append({"agent_id": aid, "error": str(e)})
```

错误信息只有 `str(e)`，缺少异常类型和 traceback。对批量操作排查不利。
